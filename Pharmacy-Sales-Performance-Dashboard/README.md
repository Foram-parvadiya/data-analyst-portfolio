💊 Pharmacy Sales Performance Dashboard
📌 Project Overview

The Pharmacy Sales Performance Dashboard is an interactive Power BI dashboard designed to analyze pharmacy sales data and evaluate overall business performance.

The dashboard provides insights into sales trends, product performance, and revenue distribution to help improve decision-making and inventory management.

🎯 Project Objectives

Analyze pharmacy sales performance

Identify top-selling medicines

Track revenue trends over time

Monitor product demand patterns

📂 Dataset Information

The dataset used in this project was collected from a pharmacy business source and represents real-world sales transactions.

For privacy and confidentiality reasons, sensitive information has been removed or anonymized.

🛠 Tools & Technologies Used

Power BI

Data Cleaning

Excel Dataset

📊 Dashboard Features

The dashboard includes several interactive visualizations:

Total Sales Overview

Top Selling Products

Sales Trends Analysis

Product Category Performance

Revenue Distribution

Users can interact with filters and slicers to explore the sales data dynamically.

📈 Key Insights

Identified the most profitable medicine categories

Observed monthly sales growth trends

Highlighted products contributing the highest revenue

Detected variations in product demand
